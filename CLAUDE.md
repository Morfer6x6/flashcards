# Flashcards App

## What this is
A small web app for studying with flashcards. The user creates question/answer
cards, reviews them by flipping each card, and marks each card as "Known" or
"Still learning". All cards are saved on the user's own device.

## Stack
- Plain HTML, CSS, and JavaScript only
- No framework (no React, no Next.js)
- No build step, no backend
- Data stored in the browser's localStorage
- Deployed to GitHub Pages

## Files
- index.html — structure
- style.css — styling
- app.js — behaviour

## How to run it
Open index.html in a web browser.

## Rules
- Do not add any new libraries or frameworks without asking me first.
- Keep everything in the three files: index.html, style.css, app.js.
- Do not store anything sensitive in localStorage (only the user's own cards).
